# InviteStudio Design References

This document tracks the approved visual references for InviteStudio. The references guide implementation; they are not UI implementation themselves.

## Design direction

- Light, Apple-inspired interface.
- White backgrounds with soft lavender and pastel pink accents.
- Rounded cards and subtle shadows.
- Clean typography and generous spacing.
- Responsive desktop, tablet, and mobile layouts.
- Consistent sidebar, navigation, buttons, cards, and forms.
- Consistent branding across every admin page.

## Product architecture context

InviteStudio will have two experiences:

### Public website

- Homepage
- Design Gallery
- Design Details
- Custom Design Request
- Checkout
- Future customer accounts

### Private admin studio

- Dashboard
- Design Gallery Management
- Custom Requests
- Orders
- Customers
- Messages
- Analytics
- Settings

The public website and private admin studio should share the same branding, typography, color language, controls, cards, forms, and responsive principles. The admin studio is the first development priority.
